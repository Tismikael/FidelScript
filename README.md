## About The Project

Fidel Learn is not meant to replace traditional language learning — it's meant to lower the
barrier to entry for people interested in learning the Fidel script.
Users work through the script one letter family at a time (34 families in total), learning each
family's seven forms before passing a short series of assessments to unlock the next.

## Built With

**Frontend**
* React + Vite 
* React Router

**Backend**
* Express
* PostgreSQL with Drizzle ORM

## Features

1. Dashboard listing all letter families belonging to the Fidel script.
    Each family is encapsulated in a lesson card which exists in one of two states, 
    locked or unlocked.
2. Each lesson shows the all the characters associated with the letter as well as a playable audio.
3. There are three types of assessments for each lesson: **Matching**,
    **Recognition**, and **Guess the Sound**. Passing them all unlocks the next available letter family.
